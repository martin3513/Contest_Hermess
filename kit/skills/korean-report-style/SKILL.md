# 한국어 보고서 문체 규칙

보고서를 읽는 사람은 수십 편을 연달아 보는 심사위원이다. **처음 30초 안에 주장과 근거가 보여야 점수가 나온다.**
그래서 이 규칙은 "읽기 쉬움"보다 "빨리 판단할 수 있음"을 우선한다.

## 1. 공통 규칙 (모든 유형)

1. **결론 먼저.** 섹션과 문단의 첫 문장은 그 부분의 주장이다. 배경 설명으로 시작하지 않는다.
2. **숫자로 말한다.** "크게 증가" 대신 "3년간 42% 증가(통계청, 2025)". 수치에는 출처를 괄호로 붙인다.
3. **출처 없는 수치는 쓰지 않는다.** 꼭 필요한데 출처가 없으면 `[출처 필요]` 를 남기고 리서치 파일에 요청을 적는다.
4. **추정은 추정이라고 쓴다.** "약 1,200명으로 추정(가정: 시장 내 점포 300곳 × 점포당 4명)"처럼 가정을 함께 쓴다.
5. **용어는 하나로.** 같은 대상을 "상인/점주/사업자"로 섞어 쓰지 않는다. 처음 정한 용어를 끝까지 쓴다.
6. **약어는 처음에 풀어 쓴다.** "탐색적 데이터 분석(EDA)" 이후에는 EDA.
7. **표·그림마다 한 줄 해석.** 표 아래에 "→ 신선식품 폐기율이 평균의 1.5배" 처럼 무엇을 보라는지 적는다.
8. **피할 표현:** "~라고 할 수 있다", "~것으로 사료된다", "매우·굉장히", "혁신적인"(근거 없이), 같은 말 반복.
9. **분량은 배점에 비례.** 배점 25점 섹션이 10점 섹션보다 짧으면 안 된다 (outline 의 분량 배분을 따른다).

## 2. 유형별 문체

### 설득형 개조식 (아이디어 제안서)

- 문단 대신 계층 글머리를 쓴다: `○`(주장) → `-`(근거) → `·`(세부).
- 글머리 문장은 명사형 또는 "~함/~임"으로 끝낸다.
  - ○ 전통시장 신선식품 폐기율이 일반 소매점의 1.5배임
    - 수요 예측 없이 경험에 의존해 발주함 (상인 설문 78%, 출처)
- 한 글머리는 두 줄을 넘기지 않는다. 넘으면 하위 글머리로 나눈다.
- 차별점은 반드시 비교표로: | 구분 | 기존 방식 | 제안 방식 |

### 기술 보고형 개조식 (데이터 분석 보고서)

- 설득형 개조식 규칙 + 재현성 문장: "~를 ~방식으로 처리함(이유: ~)".
- 모든 성능 수치는 결과 파일에서 복사한다. 소수점 자릿수를 통일한다 (예: 4자리).
- 그래프 제목은 결론형: "기온이 25℃를 넘으면 판매량이 급감" (변수 이름 나열 금지).

### 학술 서술형 (연구 보고서)

- 완결된 문장의 문단으로 쓴다. 한 문단 = 한 주장 + 근거 + 의미.
- 인용은 (저자, 연도). 참고문헌은 한 가지 양식(예: APA)으로 통일한다.
- 결과와 해석을 섞지 않는다: 결과 절에는 사실만, 논의 절에서 해석한다.

## 3. 목차 설계 규칙 (outline-designer 용)

1. 공고문의 **필수 포함 항목**과 **심사 항목**을 표로 나열하고, 각 항목이 어느 섹션에서 다뤄지는지 연결한다.
   연결되지 않은 항목이 하나라도 있으면 목차를 고친다.
2. 분량 배분: 프로필에서 `length_ratio` 가 정해진 섹션(요약·팀 소개 등)을 먼저 떼고, 남은 분량을 `weight`(공고문 배점 우선) 비율로 나눈다.
3. 섹션마다 "이 섹션의 핵심 주장 1줄"과 "넣을 표·그림"을 적는다. 작성자는 이 주장을 첫 문장으로 쓴다.
4. 목차 제목은 심사 항목의 단어를 그대로 쓴다 (심사위원이 배점표와 바로 대조할 수 있게).

## 4. 수정할 때 (writer 의 리뷰 반영)

- 심사위원·정합성 검사의 지적 사항 **만** 고친다. 지적되지 않은 문장은 그대로 둔다.
- 고친 곳마다 초안 파일 끝 `## 수정 기록` 에 "라운드 N: (지적) → (수정 내용)" 한 줄을 남긴다.
