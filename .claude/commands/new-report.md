새 대회 보고서 작성을 시작한다. 인자: `$ARGUMENTS` (첫 번째 = 보고서 유형, 두 번째 = 대회명)

1. 인자가 비었거나 유형이 `kit/profiles/` 에 없으면, 사용 가능한 유형 목록을 보여 주고 무엇을 쓸지 묻는다.
   대회명이 없으면 `contests/` 아래의 폴더 목록을 보여 주고 고르게 하거나 새 이름을 받는다.
2. `contests/<대회명>/input/` 이 없거나 비어 있으면 폴더를 만들고, 공고문·양식을 넣어 달라고 안내한 뒤 멈춘다.
3. 기존 state.json과 작업 이력을 읽고 이어간다. 처음부터 작성하라는 명시적 요청이면 새 대회명을 권한다.
4. 오케스트레이터 스킬 `contest-report` 를 이 대회와 유형으로 실행한다.
   새 작업은 준비부터 **승인 1(목차 확정)까지**, 기존 작업은 저장된 단계부터 진행한다.
   모드를 지정하지 않았다면 Orca 팀/단독 중 선택받는다. 공통 절차 WORKFLOW.md를 따른다.
5. 멈출 때 사용자에게 알릴 것 (5줄 이내): 추출한 심사 항목과 배점, 목차 파일 위치, 확인할 점, "진행"이라고 하면 작성이 시작된다는 안내.
