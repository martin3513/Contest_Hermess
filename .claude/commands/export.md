---
description: 완성된 보고서를 한글(HWPX)·Word(DOCX)·Markdown 파일로 출력한다
argument-hint: "[hwpx|docx|md] [대회명]"
---

보고서를 파일로 출력한다. 인자: `$ARGUMENTS` (형식과 대회명, 순서 무관. 형식 생략 시 프로필의 `outputs`)

1. 대회 폴더를 정한다 (생략 시 가장 최근 대회, 한 줄로 알림).
2. `_workspace/draft/`를 번호 순서로 합쳐 `output/<대회명>_보고서_<날짜시각>.md`를 만든다.
   기존 결과는 덮어쓰지 않는다. 상태에 기록된 승인 2가 없으면 초안 확인부터 진행한다.
   합칠 때 각 초안 끝의 `## 수정 기록` 은 빼고, 맨 위에 보고서 제목을 넣는다.
   `[출처 필요]` 표시가 남아 있으면 개수와 위치를 알리고 "그대로 출력할지" 묻는다.
3. `hwpx-formatter` 스킬로 출력한다.
   - `input/` 에 대회 양식 .hwpx 가 있으면 경우 B(표 칸 채우기)가 필요한지 먼저 판단하고, 필요하면 사용자에게 확인한다.
   - 기본은 경우 A(새 문서).
4. 만든 파일 경로를 알리고, 한글에서 직접 열어 확인하라고 안내한다.
5. 이 출력이 최종본이면 **승인 3** 이다: 제출은 사람이 직접 한다고 분명히 알린다.
