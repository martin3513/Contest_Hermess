# 자세한 사용법

## 1. 처음 한 번

1. Orca를 실행하고 `D:\doc\contest_hermess` 폴더를 엽니다.
2. Orca에서 사용할 Claude Code 또는 Codex의 로그인·모델 설정을 확인합니다.
3. Python 3.10 이상이 필요합니다. 터미널에서 `python --version`으로 확인합니다.
4. 폴더의 **`시작.cmd`**를 더블클릭합니다. 8번 환경 점검에서 Orca 연결을 확인합니다.
5. HWPX가 필요하면 이 폴더 터미널에서 한 번 실행합니다.

```powershell
python -m pip install -r requirements-hwpx.txt
```

런처 자체에는 추가 Python 패키지가 필요 없습니다. Git·Node·myharness 설치는 일반 보고서 작업의 필수 절차가 아닙니다.
`시작.cmd`는 하나의 진입점입니다. 이 파일만 다른 곳으로 복사하는 독립 실행 프로그램은 아니므로 저장소 전체를 함께 보관하세요.

## 2. 새 대회 시작

1. `시작.cmd` → **1번** → `2026_정책공모전` 같은 대회명을 입력합니다.
2. 보고서 유형을 고릅니다.

| 유형 | 적합한 작업 |
|---|---|
| idea_proposal | 아이디어·창업·정책 제안서 |
| data_analysis | 데이터 분석·모델 결과 보고서 |
| research_report | 연구·학술 보고서 |

3. **5번**에서 기존 대회 번호를 골라 자료 폴더를 엽니다. 공고문, 제출 양식, 참고자료를 넣습니다.
   공고 원문과 배점표가 가장 중요합니다. 팀 소개·아이디어·예산·사용 가능한 데이터가 있으면 함께 넣습니다.
   이미지 PDF는 OCR이 필요할 수 있습니다. 구형 `.hwp`는 한글에서 `.hwpx`로 저장해 넣습니다.
4. **2번 Claude Code** 또는 **3번 Codex**를 선택합니다. 기존 대회가 번호로 나오면 번호를 고릅니다. 메뉴 1에서 0번을 선택하면 새 대회명을 입력할 수 있습니다.
5. 실행 방식에서 **1 팀 작업** 또는 **2 단독 작업**을 고릅니다.
6. Orca에 열린 새 대화에서 진행 상황과 질문을 확인합니다. 런처 창은 닫아도 됩니다.

팀 작업은 담당 역할을 실제 Orca 워커로 나눕니다. 기본 조사 동시 실행은 2개이며 범위 4개를 두 번에 나눕니다.
단독 작업은 한 에이전트가 순서대로 수행하므로 비용을 줄일 수 있지만 심사가 독립 맥락에서 이루어지지 않습니다.
실행기에서 제공자를 선택해도 권한 설정은 Orca 설정을 따릅니다. 역할별 모델 배정은 `docs/MODEL_POLICY.md`를 참고하세요.
에이전트 사용량은 연결한 Claude/Codex 계정에서 발생합니다.

## 3. 자료와 결과를 구분하는 법

```text
contests/
  2026_정책공모전/
    input/                    내가 넣는 공고·양식·참고자료 (원본 보존)
    output/                   완성 보고서 MD·HWPX 등
    docs/
      requirements.md         추출한 요구사항
      outline.md              확인할 목차
      working_history/        단계별 결과와 다음 할 일
    _workspace/
      research/               조사 자료
      draft/                  섹션별 초안
      review/                 심사·정합성 결과
      state.json              현재 단계·점수·승인 기록
      orchestration.json      Orca 팀 식별자와 실행 상태
      launches/               실행 영수증
```

결과는 메뉴 **6번**, 현재 단계는 **4번**에서 확인합니다. 새 출력은 날짜시각이 붙은 파일로 저장합니다.
대회 자료와 결과는 Git에 올라가지 않습니다. PC 이전·복구를 위해 `contests/`는 별도로 백업하세요.
Git에 결과도 보관하려면 내용을 검토한 뒤 필요한 파일만 명시적으로 추가하세요.

## 4. 확인하며 진행하기

승인 지점은 목차, 초안, 최종 파일의 세 번입니다. **기존 Orca 대화에서** 다음처럼 입력합니다.

```text
목차 확인했어. 승인하고 진행해줘.
3장 예산은 총 500만 원으로 수정해줘. 실제 견적과 가정을 구분해줘.
초안과 점수 확인했어. 출력해줘.
최종 파일 확인했어. 작업 완료로 기록해줘.
```

마지막 제출은 직접 합니다. 자동 점수는 내부 검토용이지 대회 공식 점수가 아닙니다.
HWPX는 한글에서 페이지 수·글꼴·표 잘림·양식 적합성을 확인하세요. 구조 검증만으로 외형을 보장할 수 없습니다.
DOCX는 Pandoc이 있을 때 변환합니다. PDF는 한글에서 저장하는 방법을 안내합니다.

## 5. 다음 날 이어가기 / 제공자 바꾸기

가능하면 Orca의 **기존 대화**를 열고 `이 대회 이어서 진행해줘`라고 입력합니다.
`시작.cmd`를 다시 실행해 같은 대회를 중복 시작하면 실행 기록 때문에 차단됩니다.

새 대화가 꼭 필요하거나 Claude↔Codex를 바꾸려면:

1. 기존 대화가 완료/승인 대기 상태인지 확인합니다. 실행 중이거나 상태 불명인 워커가 있으면 기존 코디네이터에게 정리·복구를 요청합니다.
2. `시작.cmd` → **7번** → 대회명 → 확인 내용을 읽고 `확인`을 입력합니다.
3. 2번/3번에서 같은 대회명으로 새 대화를 엽니다. 파일의 상태와 이력을 읽고 재개합니다.

7번은 실행 잠금 기록만 보관 폴더로 옮깁니다. 실행 중인 AI를 종료하거나 보고서를 초기화하지 않습니다.
새 대화는 이전 채팅 기억을 공유하지 않으므로 중요한 결정은 반드시 작업 이력에 남겨 달라고 하세요.

## 6. 실행 파일 없이 대화로 사용

Orca에서 이 폴더의 Claude Code 또는 Codex 대화를 열고 아래처럼 입력해도 됩니다.

```text
WORKFLOW.md에 따라 2026_정책공모전을 idea_proposal 유형으로 진행해줘.
모드는 orchestrated이고, 현재 제공자로 Orca 워커를 감독해줘.
```

Claude 단축 명령: `/new-report idea_proposal 2026_정책공모전`, `/status`, `/review`, `/export hwpx`.
Codex는 `$contest-report` 또는 자연어로 요청하세요. Claude 전용 슬래시 명령을 Codex 공통 명령으로 가정하지 않습니다.
스킬이 표시되지 않으면 프로젝트를 연 새 대화에서 다시 확인하거나 WORKFLOW.md를 직접 지정하세요.

## 7. 터미널 명령

```powershell
python -X utf8 start.py init "2026_정책공모전" --profile idea_proposal
python -X utf8 start.py launch "2026_정책공모전" --agent claude --mode orchestrated
python -X utf8 start.py launch "2026_정책공모전" --agent codex --mode orchestrated --preview
python -X utf8 start.py status
python -X utf8 start.py doctor
```

`--preview`는 폴더와 실행 인자를 준비하고 AI는 실행하지 않습니다.
`--profile` 기본은 idea_proposal입니다. 다른 유형의 기존 대회는 해당 `--profile`도 지정합니다.

## 8. 문제 해결과 수정할 곳

| 상황 | 대응 |
|---|---|
| Python이 없거나 실행 안 됨 | Python 3.10 이상 설치·PATH 확인 후 다시 실행 |
| orca 명령 없음 | Orca CLI 설치·PATH 확인. 임의의 다른 실행 파일로 재시도하지 않음 |
| Orca가 연결되지 않음 | 앱을 실행하고 이 폴더를 연 뒤 메뉴 8에서 점검 |
| 실행 응답 유실/오류 | `_workspace/launches/` 영수증과 기존 Orca 대화 확인. 무작정 다시 실행하지 않음 |
| 이미 실행 기록이 있음 | 기존 대화에서 재개. 새 대화가 필요하고 워커가 정리됐을 때만 메뉴 7 |
| 조사 도구가 없음 | 자료를 input에 추가하거나 검색 가능한 환경 사용. 출처를 지어내지 않음 |
| HWPX 실패 | requirements-hwpx.txt 설치 확인, MD 보존, 에러를 에이전트에게 전달 |
| 자료 유형을 바꾸고 싶음 | 기존 대회를 보존하고 새 대회명으로 시작 |

작업 순서·승인은 `WORKFLOW.md`, 역할은 `agents/`, 문체·채점·출력은 `kit/skills/`,
보고서 유형은 `kit/profiles/`에서 수정합니다. 어댑터/명령을 동기화하려면 `python scripts/sync_adapters.py`를 실행합니다.
`.claude/`와 `.agents/`는 얇은 연결 파일이며 실제 절차를 중복 수정할 필요가 없습니다.
