# 현재 요구사항

- 이 폴더에서 대회별 작업을 반복한다. 공통 진입점은 `시작.cmd`다.
- Orca에서 Claude Code와 Codex를 선택한다. 공통 절차는 WORKFLOW.md다.
- input과 output을 분리하고 원본·기존 결과를 보존한다.
- 역할 6종, 실제 Orca 팀 감독과 단독 실행을 구분한다.
- 공고 분석 → 조사 → 목차 승인 → 작성·심사 → 초안 승인 → 출력 → 최종 확인.
- 자료·결과는 기본 Git 제외, 도구·지침·예제만 저장소에 보관한다.
- 재개 시 파일 상태·결정 이력을 읽고 중복 실행을 차단한다.
- 모델·권한은 Orca 설정을 따른다. 제출·이메일은 사람이 직접 한다.
- myharness 생성기와 Node.js 인터뷰에 대한 필수 의존성을 제거한다.
